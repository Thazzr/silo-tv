# Agent Instructions

**`CLAUDE.md` is the single source of truth** for the rules and conventions of this repository — workflow, webOS platform rules, Silo API rules, TV UI rules, testing, and the per-phase commit + changelog process. Read it first.

This file exists only so agents that look for `AGENTS.md` by convention find the pointer; it is intentionally **not** a second copy of the rules (a duplicated ruleset drifts out of sync).

- Operative rules & workflow → [`CLAUDE.md`](CLAUDE.md)
- Feature plan and phases → [`docs/roadmap.md`](docs/roadmap.md)
- Setup, commands, TV installation, tests and CI → [`docs/development.md`](docs/development.md)
- Generated changelog (do not hand-edit) → `CHANGELOG.md`, config [`cliff.toml`](cliff.toml)
