# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive. Welcome people of every background and level of experience. Criticise ideas, not people. Harassment, insults and personal or political attacks have no place here, in issues, pull requests, discussions or anywhere else the project is represented.

## Reporting

Report unacceptable behaviour to the maintainer, GitHub user [Thazzr](https://github.com/Thazzr). If you do not want to raise it in public, open a short issue that asks for a private contact without naming details; everything else is then handled privately. Reports are treated confidentially.

The maintainer may edit or remove comments, commits and other contributions that break this code, and may ban people from the project, temporarily or permanently, as the Contributor Covenant's enforcement guidelines describe.
